## 📋 90 秒结构化介绍（推荐版）

### 1. 一句话定位（10s）
> "用尼采'孩子'哲学 + AI，帮 20-30 岁奥德赛时期的年轻人重新发现'我愿意'做的事。"

### 2. 痛点（15s）
> "市面上的 MBTI、职业规划工具都在用选择题匹配数据，但意义感是体验问题，不是信息问题。用户要的不是被告知'你适合什么'，是'看见自己已经在做某件事时发光'。"

### 3. 解决方案（25s）
> "我做了个叫'孩子的游戏'的产品。用户和扮演查拉图斯特拉的 AI 进行 3 轮对话——回忆 / 觉察 / 命名。最后生成一张'孩子宣言'卡片。
>
> 关键设计：**Co-Creation 机制**——AI 给候选、用户自己选、自己命名。用户拿到的不是 AI 的产物，是自己的作品。这才是值得分享的内容。"

### 4. 技术实现（15s）
> "Next.js 全栈 + Supabase 数据库 + DeepSeek 大模型 + 自研 Prompt Engineering 实现了查拉图斯特拉的角色一致性。"

### 5. 你的能力体现（15s）
> "做这个项目让我锻炼了四种能力：①识别竞品本质差异的产品哲学能力 ②主导 Co-Creation 机制设计的体验设计能力 ③把抽象哲学落成可交互产品的转化能力 ④跨领域结合的差异化定位能力。"

### 6. 未来规划（10s）
> "下一步做宣言画廊 + 用户系统，长期看可以延伸成职业探索 / 心理咨询辅助 / 内容订阅。"

## ❓ 高频追问 + 参考答案

### Q1：你为什么做这个项目？
> "我自己就是奥德赛时期的人。哲学专业 + AI 兴趣，这个组合没人铺好路。我决定'成为那个创造新路的孩子'。产品即隐喻——做产品的过程本身就在实践'孩子'精神。"

### Q2：为什么是尼采？为什么是'孩子'？
> "三段变化（骆驼→狮子→孩子）里，主流市场都在前两段打转（忍受和反抗），但真正稀缺的是'创造'。我选'孩子'是因为：第一，差异化最强；第二，它呼应了用户群体（年轻人）的真实状态；第三，它和我做产品本身的体验是统一的。"

### Q3：MBTI 也是体验式，你怎么差异化？
> "MBTI 是被动匹配——你答题，它给你结果。我做的是主动发现——AI 通过对话'看见'你，过程中你会重新认识自己。更关键的是，用户拿到的不是 MBTI 报告，是'我参与创造的作品'，分享动机完全不同。"

### Q4：Co-Creation 怎么保证质量？
> "传统做法是 Prompt 调优或多次生成让用户选，但那是把用户当消费者。我让用户参与生成过程——AI 给候选、用户选/改、用户起名。这样用户拿到的内容必然是自己满意的，质量下限由用户保证。"

### Q5：你这个产品有什么商业价值？
> "短期：靠"宣言分享"裂变（朋友圈截图）。中期：可延伸到职业规划、心理辅助、教育场景。长期：可做成内容订阅 + 一对一深度咨询。"

### Q6：技术上最有挑战的是什么？
> "让 AI 保持'查拉图斯特拉'的角色一致性。我用了三层 Prompt 设计：①基础角色设定 ②价值观边界 ③分阶段引导。同时控制 temperature 0.8 平衡创造性和稳定性。"

### Q7：如果让你重做一次，你会改什么？
> "我会更早引入 Supabase 的用户系统。因为现在每个用户的对话不保存，重做时他们会希望看到自己的'孩子'轨迹。这是产品经理的教训：MVP 阶段就要想好"用户复访"的钩子。"
