### 起源
用户的目标很明确：做作品集，差异化竞争。他面临的核心问题：
1. 哲学专业 + AI 产品 = 没有现成路径

3. 之前的尝试因"上下文崩坏"半途而废

### 痛点诊断
他之前的"厨房新手做饭"网页失败 3 大痛点：
1. **只有纯前端没有后端** → 没法做交互、没法调用 AI
2. **对话上下文崩坏** → 项目做到一半换对话就接不上
3. **缺图片 API** → 页面只能放占位图

### 解决方案设计
针对这 3 个痛点，本次项目设计了对应解法：
1. 选 **Next.js 全栈** → 前后端一体
2. **三层文档接力机制**（PRD/架构/progress）→ 任何新 AI 读文档就能接手
3. **DeepSeek API + 即梦生图** → 解决 AI + 图片

## 3. 产品定义

### 名称
**「孩子的游戏」**（英文：Child's Game）

### 一句话定位
用尼采"孩子"哲学 + AI，让 20-30 岁奥德赛时期年轻人通过 3 轮对话重新发现自己"愿意"做的事。

### 目标用户

**核心用户**：
- 22-28 岁，学历本科以上
- 正在经历"意义危机"
- 场景：凌晨emo、面临职业选择、人际关系困扰

**次级用户**：
- 哲学 / 人文专业学生
- 内容创作者

**不做**：
- 学术研究者
- 心理咨询替代品

### 核心痛点

| 痛点 | 现有方案 | 我们怎么做 |
|---|---|---|
| 不知道自己喜欢什么 | MBTI、霍兰德测试 | AI 用"孩子"哲学挖掘"做的时候忘记时间"的瞬间 |
| 一直在忍受或反抗 | 鸡汤、励志书 | 引导看到第三种可能：创造 |
| 找不到存在意义 | 哲学书、心理咨询 | 尼采"孩子"是世俗化的意义方案 |

### 核心机制：Co-Creation（用户参与式生成）

这是产品的**灵魂创新**：

> AI 不直接给答案，而是**给 3 个候选 → 用户选一个 + 可编辑 → 用户选视觉风格 → 用户给卡片起名 → 生成专属"孩子宣言"卡片**

这个机制的设计逻辑（来自用户自己的洞察）：
> "如果让用户去选文案，他更像消费者；让他参与，他才成为创造者。"

### 5 步体验流程

```
1. 对话 0-2: 3 轮对话（回忆/觉察/命名）
   ↓
2. 生成候选: AI 自动生成 3 个版本的"孩子宣言"
   ↓
3. 选择候选: 用户选一个 + 可编辑
   ↓
4. 风格 + 命名: 用户选 4 种视觉风格 + 给卡片起名
   ↓
5. 完成卡片: 展示最终卡片 + 一键复制
```

### 视觉风格
- **哲学主题色**: 羊皮纸（背景）+ 墨色（文字）+ 金色（点缀）
- **字体**: 衬线体（Georgia + 宋体）
- **整体调性**: 古典、温暖、克制

## 4. 技术架构

### 选型理由

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 + 后端 | Next.js 14 (App Router) | 前后端一体，新手友好，部署简单 |
| 数据库 + 认证 | Supabase | 免费额度够用，自带用户系统，PostgreSQL 强大 |
| AI 大模型 | DeepSeek | 中文能力顶级、角色扮演强、价格 1/30 的 GPT-4 |
| AI 生图 | 即梦 AI | 暂未接入 |
| 部署 | Vercel + Supabase | 暂未部署 |
| 样式 | Tailwind CSS | 自定义哲学主题色 |

### 关键文件说明

- **`lib/ai/prompts.ts`**: 查拉图斯特拉角色 prompt（4 阶段），是产品核心 IP
- **`app/api/chat/route.ts`**: 聊天 API（处理 3 轮对话）
- **`app/api/generate-candidates/route.ts`**: 候选生成 API（Co-Creation 关键）
- **`components/ChatWindow.tsx`**: 主状态机（5 步骤切换）
- **`lib/utils/storage.ts`**: localStorage 工具（历史保存）

### 数据流

```
用户输入
   ↓
ChatWindow 组件
   ↓ fetch
/api/chat (3 轮对话)
   ↓
DeepSeek API
   ↓ JSON
ChatWindow 渲染
   ↓
3 轮后自动调 /api/generate-candidates
   ↓
Co-Creation 阶段（选候选/风格/命名）
   ↓
最终 DeclarationCard + 复制
   ↓
localStorage 保存
```
